# Counter Program

A simple and interactive **Counter Program** built using **HTML, CSS, and JavaScript**.

This project was created as a hands-on practice project while learning the fundamentals of front-end web development. It focuses on understanding how HTML structures a webpage, how CSS styles and lays out elements, and how JavaScript interacts with the DOM to create dynamic functionality.

## Features

* ➕ **Increment** — Increases the counter by 1
* ➖ **Decrement** — Decreases the counter by 1
* 🔄 **Reset** — Resets the counter back to 0
* 🎨 Clean and simple user interface
* ✨ Button hover effects
* 📐 Flexbox-based button alignment
* ⚡ Real-time counter updates using JavaScript DOM manipulation

## How It Works

The counter starts at `0` and can be controlled using three buttons:

| Button        | Function                   |
| ------------- | -------------------------- |
| **Increment** | Increases the counter by 1 |
| **Decrement** | Decreases the counter by 1 |
| **Reset**     | Sets the counter back to 0 |

The counter value is stored in a JavaScript variable and the displayed value is updated dynamically through DOM manipulation.

## Technologies Used

* **HTML5** — Structure and content
* **CSS3** — Styling, layout, hover effects, and Flexbox
* **JavaScript** — Counter logic and DOM manipulation
